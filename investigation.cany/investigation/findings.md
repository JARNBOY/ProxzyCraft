# Findings

- **fnd_1** The original registers its proxy port as 9090 (`w8 = 0x2382` next to the CurrentProxyPort key) in the one defaults initialiser at 0xf34bc, which is why the POC's default is 9090. (Seen it; evidence: ev_afd4a3ca28a30ea6abd00bc557cd69c1e9ba8128e5c9a500abdedf630c1d5fb5)
- **fnd_2** The same initialiser writes `w8 = 0x1e` (30) for `composeTimeoutConfig`, so Compose's default send timeout is 30 seconds; the POC's 30 s default and 15/60/Off presets follow it. (Seen it; evidence: ev_afd4a3ca28a30ea6abd00bc557cd69c1e9ba8128e5c9a500abdedf630c1d5fb5)
- **fnd_3** Map Local's default response delay comes from its own small default function at 0x40c9c, which registers mapLocalResponseDelay = 10 (milliseconds), not seconds; the POC keeps the value in ms and applies the eight DelayTimePreset presets on top. (Seen it; evidence: ev_0328e07ef02e5cf60aac74112354972d9e44e7ad5962a96d4a4c52954f513dc5)
- **fnd_4** Map Local's delay menu is the Swift enum DelayTimePreset, whose contiguous cases are noDelay, oneSecond, twoSeconds, threeSeconds, fiveSeconds, tenSeconds, thirtySeconds and sixtySeconds, with a typed customDelayTimeMs field. The POC uses exactly that list and treats the last preset (60 000 ms) as the ceiling for typed values, replacing its earlier 10 s clamp. (Seen it; evidence: ev_9df7b1f7b973910c11c1060b5464e883fa53bdccd3546a1186393211683dae9f)
- **fnd_5** The original's BreakpointAbortOption cases are dropConnection, return503 and return429, in that order, and the defaults initialiser stores raw 0 for breakpointAbortOption — so a fresh install aborts a breakpoint by dropping the connection, not by answering 503. (Seen it; evidence: ev_b24733559db5bd942a9400a2fe02b32634ebf945df93cf5be84fa633e5b20c9e, ev_afd4a3ca28a30ea6abd00bc557cd69c1e9ba8128e5c9a500abdedf630c1d5fb5)
- **fnd_6** Compose's "Automatically Follow Redirects" switch is on by default: the getter at 0x43050 returns true for isComposeFollowRedirects, and the defaults initialiser 0xf34bc writes 1. The POC's Composer now starts with the switch on and passes -L to curl. (Seen it; evidence: ev_1437b11e7c069b23d4bcfc6380dad980212ed7dab7095487cbf204148011edb4, ev_afd4a3ca28a30ea6abd00bc557cd69c1e9ba8128e5c9a500abdedf630c1d5fb5)
- **fnd_7** The embedded request editor uses 2-space indentation: 0x42960 returns 2 for monacoEditorTabSize and the defaults initialiser writes the same 2. The POC's cURL/code pretty-printers now use that constant instead of four spaces. (Seen it; evidence: ev_c729371ae82c0b22ec5b7157708a4cedbf227a46e2750112d05c813cca899531, ev_afd4a3ca28a30ea6abd00bc557cd69c1e9ba8128e5c9a500abdedf630c1d5fb5)
- **fnd_8** Map Local's large-fixture warning is a real 20 MB comparison in function 0x1bb608, whose message is the string at 0xfb01b0: "File size is bigger than 20Mb could impact the performance!". The POC uses 20 * 1024 * 1024 bytes for the same check. (Seen it; evidence: ev_de7dc34270e94812ca08acc6e71670569accb842b1dade5df1ca45af57b7466d)
- **fnd_9** The original's cURL generator (0x2cd188) always appends --proxy http://localhost:<port>, sends inline bodies as --data-binary @- and file bodies as --data-binary "@<path>", adds the multipart Content-Type header itself and recomputes Content-Length. The POC's Copy as cURL now includes the live proxy by default and omits the stale Content-Length. (Seen it; evidence: ev_8470c66a5f8a23933475c69e240f2ac4cbfd2eab5e58dfee0606458aa5ed0386, ev_afd4a3ca28a30ea6abd00bc557cd69c1e9ba8128e5c9a500abdedf630c1d5fb5)
- **fnd_10** GraphQL matching reads the operation name from the graphQLQueryName body key (helper 0x4bdd4); the label builder at 0x28fe9c falls back to the literal <Missing Query Name> when it is absent. The POC keeps the same key and fallback text. (Seen it; evidence: ev_44ec0d015f2ee7763bf15a4ed040009be065cf5283c77831a0fb02bdb4a7485e, ev_987de3070379b03ba4b46ea6d012b7a08d8ade10ea11f980094e5a3b87a9a9d6)
- **fnd_11** Map Local's linked-fixture auto-save is on by default: 0x421cc returns true for isAutoSaveOnMapLocalFile. The POC is not claiming the original's 2-second debounce from code, only that the switch starts enabled. (Seen it; evidence: ev_3bd7e9b4eb98baed0af3d331c158ce45441309ed68c2006c388d19f77ab4cb5c)
